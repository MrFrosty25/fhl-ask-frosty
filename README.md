# fhl-ask-frosty

Ask Frosty, the assistant inside Frosty's Holiday Lighting's platform.

**What it does**
- Looks things up: people, a person's history, leads, quotes waiting, pipeline
  numbers, money by season.
- Takes action, after you tap Confirm: log a call/text/voicemail/email, set a
  next action, mark booked / lost (with reason) / still deciding, change the
  owner, make a call list.
- Writes texts and emails you send from your own phone or mail.

**How it is safe**
- Nothing changes until you tap Confirm on the card.
- Confirm uses the same button endpoints as the screens, under your login.
- It never sends a message to a customer by itself.

See `CLAUDE.md` for the rules, `docs/WISHLIST.md` for what it should learn
next, and `docs/LESSONS.md` for mistakes and the rules they produced.
